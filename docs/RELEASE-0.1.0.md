# Tablyfern 0.1.0

First private release for Windows x64. Open JSON, JSONL or NDJSON and save a single table or a workbook with one tab per file. The release includes English and Korean UI, guides, and synthetic samples. Extract the portable ZIP and run `Tablyfern.exe` from the extracted folder. Verify the ZIP against `SHA256SUMS.txt`.

See the [third-party notices and corresponding sources](https://github.com/hobby-programmer-5000/tablyfern/blob/v0.1.0/THIRD-PARTY-NOTICES.md).
